Dashboard

Review training activity, bodyweight and performance trends. Training days count dates with logged sets. Performance comparisons use eligible complete sets with matching load units.

Program

Choose a workout and a 60-minute or abbreviated 30-minute plan. The shorter mode uses the template’s marked short-workout exercises. Customize template slots and exercise roles here. A plan’s Log button opens a new set in Workout; it does not mark the workout complete.

Workout

Check the local workout date and exercise, then enter weight, unit and reps. Keep units consistent when comparing performances. RPE describes perceived effort; RIR records estimated reps left in reserve. Notes capture context, while pain and pain area record discomfort. Pain tracking is a record, not a diagnosis; stop or modify an exercise that causes pain.

Use the approximate/incomplete option when a record is uncertain. Missing values are not treated as zero. When correcting an incomplete record, use Mark complete or uncheck Approximate / incomplete once the values are reliable, then Save changes. Editing values alone preserves the flag. Add set saves a new record; Save changes updates the record you are editing.

Guided workouts

In Workout, choose a saved workout, date and approximate 30/60-minute mode, then Start workout. The 30-minute mode keeps the existing abbreviated slots; neither mode guarantees a duration. No target sets, reps, rest times or progression advice are prescribed.

Log current exercise opens its set form. Enter the actual load, unit and reps, then Log guided set; enter another set to log again. Previous performance is informational and separated by unit. Done and Skip are explicit choices, independent of logging or Previous/Next. Navigation never marks an exercise complete. Controls beside the form let you mark Done, Skip or move Next without scrolling back to the workout card.

A session-only substitute changes subsequent sets for the planned slot, leaving earlier sets and the permanent template unchanged. Reloading or reopening restores saved position, substitutions, statuses and logged sets. Partially entered form values are not backed up or restored; save sets before leaving. Unsaved form input requires confirmation before guided navigation discards it.

Only one workout can be active. Existing active sessions require Enable guidance and keep all prior sets; no completion is inferred. Finish workout can retain pending exercises after confirmation. Use manual logging keeps the existing manual form available; while a session is active, manual sets attach to that session without inventing a planned-slot association.

History

Review explicit sessions with their saved plan name, mode, status and ordered sets. Cards start collapsed; tap anywhere in a card header to show or hide its details. Expand all and Collapse all affect the cards in the current source filter. Cards keep their state while you remain in History; returning to History starts collapsed again. Multiple workouts on one date remain separate. Collapsed rows preview two exercise names and a count of the remaining exercises. Expand a row for the full list, mode/status and record details. Within a workout, tap an exercise summary to show or hide its sets. Exercise groups open independently and preserve consecutive recorded order; an exercise repeated later remains a separate group. Exercise choices last for this History visit. Expand all and Collapse all control workout cards and retain those exercise choices. Legacy/sessionless records are grouped by date for display only, without creating sessions. Source filters show matching sets and keep session order; sessions without matching sets are omitted while a filter is active. Empty sessions remain visible in All history. Expand Record details for all saved fields. The pencil edits a set; the trash icon deletes it after confirmation. Swipe the table horizontally to reach additional columns on a small screen. Incomplete records remain marked, and imported records retain their source. Guided exercise status shows planned/current exercise selections and explicit pending, completed or skipped status; individual set records remain authoritative for actual exercises performed.

Exercises

During an active workout, save a Session note for workout-wide context or an Exercise/session note for one exercise occurrence. Set notes apply only to the set being logged. Exercise Detail keeps Durable setup notes separate from dated workout observations. Use complete JSON backups to transfer all note scopes. Unsaved notes stay visible for retry after a failed save, but are not recovered after reload.

Browse the exercise library and select an exercise to review its history, latest recorded set and performance trends. Latest and best comparable performance can describe different sets. The # Sessions count includes explicit workouts plus distinct dates for legacy/sessionless records; those date groups do not imply inferred sessions.

Data and backups

Your database is stored locally for this browser and site address. It is not automatically shared with another browser, device or address. Clearing browser data can remove it.

Use Backup or Export JSON regularly and verify that the file is saved. A complete JSON backup includes workout history, sessions, program settings and preferences. Export CSV is a sets-only spreadsheet export, not a complete backup.

Restore complete backup replaces the current database. Merge history only keeps current settings and existing record IDs while adding compatible history; conflicting session relationships are rejected. Export a JSON backup before restoring, merging, erasing data or restoring the original seed.

Saved sets are already durable before success is shown. If another tab changes your data, keep any needed export and reload before editing. Unsaved form inputs are not recovered after a reload.

Application versions identify the build you are using. Backup compatibility depends on the separate data schema; older applications may not read newer-schema backups.

On an enabled Preview, Data also offers an optional Supabase connection test. Save and read a short test value there. It uses a separate anonymous test identity and never uploads your workout database.

On an enabled account Preview, Data offers email-link sign-in and recovery. Request a fresh link for the same email to regain access in another browser. Sign-out only affects this browser's account session. Workouts remain local and are never uploaded by signing in.
